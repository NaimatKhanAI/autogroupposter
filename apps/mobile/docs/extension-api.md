# Extension scope

The mobile app has no browser companion, pairing endpoint or autonomous browser sharing. Firebase includes owner-scoped device display/revocation records for a future client; registration and task claims are not exposed.

A future extension requires a separately implemented and tested Firebase authentication/pairing protocol, expiring device credentials, transactional task leases, replay protection and revocation. No previous extension endpoint is deployed by this Firebase backend. Do not enable an extension against placeholder contracts.
